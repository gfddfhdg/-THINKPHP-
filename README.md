HP 开发的赏金职介招聘小程序，是面向劳务中介、人力资源服务商的开源招聘解决方案。系统以**赏金内推**为核心模式，搭配微信小程序前端，打破传统职介平台单向招聘的局限，鼓励用户推荐人才，借助裂变机制扩大人才供给，构建企业、求职者、推荐人三方共赢的招聘生态。

这套系统前端为微信小程序，无需下载，求职者打开微信即可浏览岗位、投递简历；推荐人可以查看悬赏岗位，推荐候选人，简历成功入职后申领赏金。后端基于 ThinkPHP 框架搭建，代码开源，便于二次开发、功能定制与独立部署，降低中小职介机构的开发成本，不用从零编写整套招聘业务代码。

系统内置完整赏金招聘业务模块。企业在后台发布岗位并设置推荐赏金，自定义赏金发放规则、结算节点；平台管理员审核企业资质、岗位信息，管控赏金结算；推荐人在线提交候选人简历，跟踪简历流转状态，查看面试、入职进度与赏金记录。同时支持简历库管理、消息模板推送、人才标签检索、招聘数据统计，方便中介高效管理人才资源。

ThinkPHP 成熟稳定的特性，让后台业务逻辑清晰，权限管理完善，可区分平台管理员、中介、企业、推荐人、求职者多角色权限。开发者可基于开源源码拓展功能，例如在线沟通、面试预约、电子协议、佣金对账等，适配蓝领劳务、普工招聘、灵活用工等场景。

在落地使用中，平台需要做好风控管理。严格审核岗位真实性，规范赏金结算规则，明确薪资、收费相关说明，杜绝虚假招聘、违规收费，保护求职者权益。开源源码仅提供技术底座，上线前要完成安全检测，修补漏洞，保障用户简历与个人信息安全。

对于劳务中介、人力资源创业团队而言，这套 ThinkPHP 赏金职介小程序，把内推赏金模式和小程序流量优势结合，利用人才推荐裂变拓宽招聘渠道，减少获客成本，打造一套可自主部署、可灵活二次开发的线上职介招聘平台。
